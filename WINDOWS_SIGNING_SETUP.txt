Archive Scout 3.0 Beta 1.3.1 Windows signing setup

The application code and networking behavior are unchanged from Beta 1.2.1.
The Windows build remains PyInstaller onedir, with UPX disabled and stable version metadata.

Repository variable:
ENABLE_WINDOWS_ARTIFACT_SIGNING=true

Repository variables:
WINDOWS_SIGNING_ENDPOINT=https://<region>.codesigning.azure.net/
WINDOWS_SIGNING_ACCOUNT_NAME=<account name>
WINDOWS_SIGNING_PROFILE_NAME=<certificate profile>

Repository secrets:
AZURE_CLIENT_ID
AZURE_TENANT_ID
AZURE_SUBSCRIPTION_ID

Tagged releases intentionally fail before publication when signing is not enabled.
Manual workflow builds remain unsigned so the packaging can be tested before signing is configured.
